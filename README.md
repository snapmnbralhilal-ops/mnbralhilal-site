# منبر الهلال — الموقع

موقع قناة منبر الهلال: مباريات ونتائج الهلال، ترتيب دوري روشن والدوري الإنجليزي، مباريات اليوم ونتائج أمس حول العالم، وأخبار تنكتب تلقائياً من البيانات.

## كيف يشتغل

- **البيانات** تجي من [API-Football](https://www.api-football.com/) عن طريق `scripts/fetch-data.js`، وتنحفظ في `data/site.json`.
- **الخطة المجانية** ما تسمح بطلبات الموسم الحالي (جدول فريق / ترتيب)، فالسكربت يجمع **مباريات كل يوم** في `data/archive/`، ومنها يبني جدول الهلال ويحسب ترتيب دوري روشن والإنجليزي بنفسه (فوز ٣، تعادل ١، ثم فارق الأهداف ثم الأهداف المسجلة).
- **التحديث التلقائي**: GitHub Actions يشغّل السكربت كل ساعتين (`.github/workflows/update-data.yml`): طلبين بكل تشغيلة (اليوم وأمس) + ١٤ طلب مرة باليوم للأيام الجاية. أول يوم يجمع أيام الموسم القديمة على دفعات (٢٠ يوم بكل تشغيلة).
- **الأخبار** تنكتب تلقائياً من النتائج والترتيب (بدون أي تكلفة إضافية).
- **الصفحة** (`index.html` + `assets/`) تقرأ `data/site.json` وتعرضه، وتعيد القراءة كل ١٠ دقائق.

## الإعداد (مرة وحدة)

1. **أضف مفتاح API-Football كسر (Secret):**
   Settings ← Secrets and variables ← Actions ← New repository secret
   - الاسم: `API_FOOTBALL_KEY`
   - القيمة: مفتاحك من لوحة تحكم API-Football
2. **شغّل أول تحديث يدوياً:** تبويب Actions ← «تحديث بيانات الموقع» ← Run workflow.
3. **انشر الموقع:** Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `(root)`.
   (GitHub Pages المجاني يحتاج المستودع يكون Public. المفتاح يبقى سري في Secrets حتى لو المستودع عام.)

## تعديلات شائعة

- **اسم فريق يطلع بالإنجليزي؟** أضفه في `assets/names.js` داخل `TEAMS`.
- **تبي دوري يظهر في مباريات اليوم؟** أضف رقمه في `PRIORITY` داخل `scripts/fetch-data.js`.
- **أخطاء من الـ API** (مثل قيود الخطة المجانية) تنحفظ في `data/site.json` تحت `errors`.

## الإعلانات والرعاة

كل الإعلانات في ملف واحد: `data/ads.json`. أي مكان فاضي `[]` ما يظهر في الموقع أبداً.

| المكان | وين يظهر | المقاس المقترح للصورة |
|---|---|---|
| `match_sponsor` | داخل بطاقة المباراة القادمة: "المباراة برعاية …" | شعار عرضي، ارتفاع ٨٠ بكسل تقريباً |
| `top` | بانر عريض تحت بطاقة المباراة | 1180×180 (على الجوال يتقص لـ 3:1 من الوسط) |
| `between` | بين "مباريات اليوم" و"نتائج أمس" | 728×120 |
| `sidebar` | مربع في العمود الجانبي | 600×600 |
| `sponsors` | شريط "رعاة منبر الهلال" آخر الصفحة | شعارات، ارتفاع ١٠٠ بكسل تقريباً |

### إضافة إعلان
1. ارفع صورة الإعلان داخل مجلد `assets/ads/` (من GitHub: Add file ← Upload files).
2. عدّل `data/ads.json` وأضف الإعلان في المكان اللي تبيه:

```json
"top": [
  { "title": "اسم الراعي", "image": "assets/ads/banner.jpg", "link": "https://موقع-الراعي.com", "from": "2026-10-10", "to": "2026-11-10" }
]
```

- `link` اختياري — رابط يفتح لما أحد يضغط الإعلان.
- `from` و`to` اختيارية — الإعلان يظهر بس بين التاريخين ويختفي لحاله بعد ما تنتهي المدة.
- `"active": false` يوقف الإعلان مؤقتاً بدون ما تحذفه.
- لو حطيت أكثر من إعلان بنفس المكان، يتبدّلون عشوائياً مع كل زيارة (ما عدا `sponsors` تظهر كلها).
- كل إعلان ينكتب عليه "إعلان" تلقائياً، والروابط تفتح بصفحة جديدة.

## صفحات الموقع
| الصفحة | الملف | المحتوى |
|---|---|---|
| الرئيسية | `index.html` | المباراة القادمة، آخر نتيجة، الهلال في الدوري، آخر التصاميم، فيديو منبر، أبرز الأخبار |
| المباريات | `matches.html` | مباريات الهلال (القادمة والنتائج)، مباريات اليوم حول العالم، نتائج أمس |
| الترتيب | `standings.html` | ترتيب دوري روشن كامل، الدوري الإنجليزي |
| التصاميم | `designs.html` | معرض كل التصاميم |
| فيديو | `videos.html` | فيديوهات تيك توك |
| الأخبار | `news.html` | كل الأخبار |
| الفئات السنية | `youth.html` | مباريات وترتيب وأخبار تحت 21 |

- **الهيدر والقائمة والفوتر وشريط الجوال السفلي** كلها في ملف واحد: `assets/layout.js`. تعديل رابط أو إضافة صفحة للقائمة يصير هناك مرة وحدة.
- **شريط "عاجل"** ما يظهر إلا لو فيه خبر عاجل (مثل مباراة الهلال المباشرة). تقدر تخلي أي خبر عاجل بإضافة `"breaking": true` له.
- **شعارات الأندية**: لو شعار نادي من API طلع بجودة سيئة، حط شعاره (PNG شفاف) في `assets/teams/` وأضف اسمه في `LOCAL_LOGOS` داخل `assets/app.js`.

## بعد أي تعديل على التصميم أو الكود
غيّر رقم `?v=` في كل صفحات الموقع (`index.html` و`matches.html` و`standings.html` و`designs.html` و`videos.html` و`news.html` و`youth.html`) عشان متصفحات الزوار تجيب النسخة الجديدة بدل القديمة المحفوظة عندهم.

## الفئات السنية (تحت 21) — تعبئة يدوية
API-Football ما يغطي دوري تحت 21، فالقسم يقرأ من `data/youth.json`:
- `upcoming`: المباريات الجاية — `{ "date": "2026-10-12T18:05:00+03:00", "home": "الهلال", "away": "الوطن", "round": "الجولة 6", "venue": "ملعب نادي الهلال" }`
- `results`: النتائج — نفس الشكل + `"homeGoals": 2, "awayGoals": 1`
- `table`: الترتيب (يظهر أول 8) — `{ "team": "الهلال", "played": 5, "win": 3, "draw": 1, "lose": 1, "gf": 12, "ga": 6, "points": 10 }`
- `news`: أخبار الفئات السنية — `{ "title": "…", "body": "…", "tag": "تحت 21" }`
- `updated`: تاريخ آخر تحديث للترتيب (يظهر "حتى 8 أكتوبر").
المباراة تختفي من "الجاية" لحالها بعد 3 ساعات من موعدها — انقلها لـ `results` مع النتيجة.

## تصاميم منبر (بطاقة المباراة وغيرها)
- ارفع التصميم في `assets/designs/` وأضفه في `data/designs.json`:
```json
{ "id": "2026-10-10-hilal-ittihad-match-card", "type": "بطاقة المباراة", "title": "الهلال × الاتحاد", "date": "2026-10-08",
  "image": "assets/designs/….jpg", "thumb": "assets/designs/…-thumb.jpg",
  "match": { "date": "2026-10-10T21:00:00+03:00", "home": "الهلال", "away": "الاتحاد", "competition": "دوري روشن السعودي",
             "round": "الجولة 8", "venue": "ملعب المملكة أرينا", "commentators": "…", "channel": "ثمانية" } }
```
- `match` اختياري: لو موجود، يظهر زر "بطاقة المباراة" داخل بطاقة المباراة القادمة يوم المباراة، مع المعلقين والناقل.
- ولو API ما عطى المباراة القادمة (الخطة المجانية)، الموقع ياخذ بيانات المباراة من هنا.
- كل تصميم يتكبر بالضغط، وفيه تحميل ومشاركة (واتساب / X).

## رعاة منبر
اللوقوهات في `assets/ads/sponsor-*.png` ومسجلة في `data/ads.json` تحت `sponsors`. أضف `"link"` لأي راعي عشان يصير الشعار رابط لموقعه.

## صفحة الفيديو (videos.html)
تقرأ من `data/videos.json`:
- `tiktok_user`: يوزر منبر في تيك توك (بدون @) — يعرض حساب منبر وآخر فيديوهاته تلقائياً.
- `featured`: فيديوهات مختارة تظهر كبيرة فوق — `{ "url": "https://www.tiktok.com/@user/video/123…", "title": "…" }`
- `clips`: لقطات المباريات من الحسابات الرسمية — نفس الشكل.

## تابعنا (حسابات التواصل)
في `data/social.json`: `x`, `instagram`, `tiktok`, `snapchat` (يوزرات بدون @)، و`whatsapp` (رابط قناة واتساب أو رقم دولي مثل 9665xxxxxxxx). أي خانة فاضية ما يظهر زرها.

## صفحة ذكرى التأسيس (founding.html)
- كل المحتوى في `data/founding.json`: البطولات (`titles` — العدد الإجمالي يتحسب لحاله)، الخط الزمني (`timeline`)، والأساطير (`legends`).
- بانر "69 عاماً" يظهر في الرئيسية تلقائياً من 1 إلى 20 أكتوبر كل سنة.

## التطبيق (PWA) والتقويم
- `manifest.webmanifest` + `sw.js` + `assets/pwa.js`: الموقع ينثبت على الجوال كتطبيق ويفتح أسرع (ويشتغل حتى لو النت ضعيف).
- شريط "ثبّت التطبيق" يطلع على الجوال؛ لو المستخدم سكّره ما يرجع أسبوع. بالآيفون يشرح الطريقة (مشاركة ← إضافة إلى الشاشة الرئيسية).
- بعد تعديل كبير على الملفات، غيّر اسم `CACHE` في `sw.js` عشان التطبيق المثبّت يجيب الجديد.
- زر "أضف للتقويم" في بطاقة المباراة القادمة وتحت مباريات الهلال (ملف .ics مع تنبيه قبل ساعة).

## التحديث المباشر (Cloudflare Worker)
- الكود في `workers/live/` — يرفعه GitHub تلقائياً لـ Cloudflare (`.github/workflows/deploy-live.yml`) ويحفظ رابطه في `data/live.json`.
- يحتاج أسرار المستودع: `CLOUDFLARE_API_TOKEN` (من قالب Edit Cloudflare Workers) و`API_FOOTBALL_KEY`. (رقم الحساب مكتوب في `wrangler.toml`.)
- يشتغل **وقت مباريات الهلال بس**: يسحب النتيجة كل `LIVE_INTERVAL` ثانية (في `workers/live/wrangler.toml`):
  - الخطة المجانية: `180` (مباراة كاملة ≈ 36 طلب).
  - باقة Pro: غيّرها لـ `15`.
- الموقع يقرأ النتيجة كل 30 ثانية وقت المباراة، ويطلع إشعار "⚽ هدف!" لما يسجل الهلال.
- `/health` على رابط العامل يعرض جدول المباريات اللي شايفها وعدد الطلبات اليوم.
